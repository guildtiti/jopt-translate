# JOPT翻訳 0.5.1 Beta

[ダウンロード・導入ガイド](https://jopt-translate-mac.directors-ai.chatgpt.site)

- 英語の “No rush if that is difficult” を、日本語で急がないよう命じる表現にせず、難しければ急ぎを求めない旨の文として保持します。
- 中国語の確認依頼に続く「如果有困难／如果有困難」は、依頼への対応が難しい場合という条件を明示します。一般的な生活上の困りごとにはこの補正を適用しません。
- 文脈・文体の調整で、フランス語の時刻前の `à` が `a` へ落ちないよう保護します。
- 複数行の追加修正を各行に対応させ、見出しの欠落・空欄・段落番号の重複・順序違いを検査します。見出し削除や要約を明示した場合は構成変更を許容します。

実AIを含む41件成功。16言語43ケースで既知4件の症状が解消し、その他39件の最終訳は前回と同一でした。中国語2件は文脈反映を確定できず、補正済みの基本訳を保持しています。

最終0.5.1 build13で、本人の⌥⇧S→3行OCR→翻訳・解説・自動別案を確認。同じ結果で「期限を木曜へ→英語へ」と続けて質問し、見出し・受付15:00・Thursdayの3行を保持しました。

Apple Silicon / macOS26.4以降 / Apple Intelligence / Googleログインが必要です。Developer ID署名・Apple公証のないBetaです。更新で権限の再登録が必要になる場合があります。別Mac初回起動・人のネイティブレビュー・全表現の品質保証は未実施です。
