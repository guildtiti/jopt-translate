# JOPT翻訳 0.4.1 Beta

[ダウンロード・導入ガイド](https://jopt-translate-mac.directors-ai.chatgpt.site)

Naniと同じ架空の例文で操作を比較し、日常的な操作を改善しました。

- 言語の検索とお気に入り。⌘⇧Pでお気に入りを切り替えます。
- 翻訳・添削・会話を切り替えても、入力中の文章と文脈を保持。
- 文脈に添える3つの例、訳文への自由な修正依頼。
- 原文のコピーと全文展開、ボタン上のコピー完了表示。
- 履歴を直接ピン留め。「表示 → コンパクトに表示」で780px幅へ切り替え。
- 丁寧・カジュアル・短く・自由な調整で、候補の出力形式と限定した条件を検査。元の文とほぼ同じ自由調整は再試行し、同じなら元の訳文を残して案内します。

実生成を含む23件成功・失敗0件。通常表示・780×700の実機操作と、公開ファイルの原本一致を確認しました。

Apple Silicon / macOS26.4以降 / Apple Intelligence / Googleログインが必要です。Developer ID署名・Apple公証のないBetaです。更新で権限の再登録が必要になる場合があります。別Mac初回起動・人のネイティブレビューは未実施。Naniと同じ品質を保証するものではありません。
