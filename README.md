# JOPT翻訳 0.6.0 Beta

[ダウンロード・導入ガイド](https://jopt-translate-mac.directors-ai.chatgpt.site)

- ショートカット11操作を、好きなキーの組み合わせへ変更・解除・初期化できます。重複・予約キーを検査し、OSで登録できない場合は元の設定を残します。
- システム・ライト・ダークの外観を選べます。翻訳・解説・履歴・設定にも反映します。
- ランチャーはメニューバーに常駐し、初期キー⌥⇧Jで表示・非表示を切り替えます。Escや他アプリへ移ったときに隠す設定も変更できます。メニューバーから通常アプリに戻せます。
- 設定は6カテゴリ。外観とキー設定は端末ごとに保存し、Googleへ同期しません。

実AIを含む44件の自動試験と配布パッケージ検査に成功。続けてキーを記録できない不具合を修正し、実キーボードで⌘⇧Nが保存されることを確認しました。

翻訳エンジンは0.5.1から変更していません。品質ページの16言語43ケースは0.5.1の生成結果で、0.6.0で全言語を再測定したものではありません。

Apple Silicon / macOS26.4以降 / Apple Intelligence / Googleログインが必要です。Developer ID署名・Apple公証のないBetaです。更新で権限の再登録が必要になる場合があります。別Mac初回起動・人のネイティブレビュー・全表現の品質保証は未実施です。
