### 必要な環境

Apple Silicon搭載Mac（M1以降）、macOS 26.4以降、Apple Intelligenceの有効化とモデルのダウンロード完了が必要です。Intel Macには対応していません。

### インストール

DMGを開き、JOPT翻訳をApplicationsへドラッグしてください。
**この試用版にはDeveloper ID署名とApple公証がありません。**
macOSが起動をブロックする場合があります。アプリの入手元を確認したうえで、[Appleの公式案内](https://support.apple.com/ja-jp/102445)を参照してください。管理対象Macでは、組織の方針によって起動できない場合があります。

### できること

- 翻訳、添削、会話の翻訳、文体・文脈の指定、用語集
- ニュアンスの解説、逆翻訳、要約、表現の調整、返信・追記案
- 画像/PDFの文字読み取り、画面範囲の文字読み取り
- ローカル履歴、検索、ピン留め、テキスト書き出し、Mac音声による読み上げ
- メニューバー、⌥⇧Tの選択テキスト翻訳、macOSサービス

原文・訳文を外部AIや解析サービスへ送信する処理はありません。履歴は利用者のMacに保存します。初回のモデル・言語データ・音声の取得にはインターネットが必要です。

### 試用版の制限

一度に20,000文字まで。長文は分割するため、段落間の文脈が弱まる場合があります。追加操作は訳文1,300文字まで。画像/PDFは30 MB、PDFは20ページまでです。

Apple Intelligenceの対応言語・品質に依存します。訳文、解説、用語集適用には誤りがありえます。数値・固有名詞・条件を原文と確認してください。チーム管理、課金、クラウド同期、自動更新はありません。Naniのコード・画像・ロゴは使用しておらず、Naniとは別の製品です。

解説は簡易的で、短い文体ラベルや原文の言い換えにとどまる場合があります。Naniと同じ品質・全機能を再現した版ではありません。選択テキストのグローバルショートカットと画面撮影は、権限を許可した状態での実機検証が残っています。
