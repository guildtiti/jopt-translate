JOPT翻訳 0.2.1 Beta

**[ブラウザのダウンロードページと導入ガイド](https://jopt-translate-mac.directors-ai.chatgpt.site)**

Apple Silicon / macOS 26.4以降 / Apple Intelligenceの有効化とモデルのダウンロード完了が必要です。Developer ID署名・Apple公証のない試用版です。

## 今回の変更

- 解説を改善。原文・訳文に含まれる表現だけを引用し、意味と使い方を表示します。よく使う一部の表現には定義したヒントを使い、それ以外はApple Intelligenceで解説します。
- 実際の入力で起きた解説生成エラーを修正。生成が長引いた場合は25秒で打ち切り、翻訳結果の操作を妨げないようにしました。
- 添削した範囲を取り消し線と色で表示します。
- 丁寧・ビジネスとカジュアルの候補を並べて比較・採用できます。
- @で始まる指示だけで、選択中の言語の文章を作成できます。
- 受信した外国語を日本語に訳した後、返信案は相手の元の言語へ作成します。
- 画面の範囲選択と取得をmacOSのネイティブAPIへ変更。Escで中止できます。
- ⌥⇧Tで選択テキスト、⌥⇧Sで画面の範囲を翻訳します。
- 外部アプリの選択翻訳・クリップボード翻訳・サービスは、前回の添削モードを引き継がず翻訳として実行します。
- 新しいOCR入力に前の訳文が残る表示を修正。編集中の入力と前回の訳文が異なる場合も表示します。

## 導入

DMGからApplicationsへドラッグします。警告時の起動方法、Apple Intelligenceの有効化、選択翻訳・画面翻訳の権限設定は、上のブラウザガイドを参照してください。

未公証Betaの更新後、権限一覧がオンでもアプリでは未許可になる場合があります。ガイドの「更新後、権限がオンなのに未許可と表示されます」に、権限項目の再登録とアプリの再起動方法を載せています。

## 検証と制限

実生成を含む15件の自動テストが成功。開発Macでは、本人の実キーボード操作による選択翻訳、範囲取得→OCR、Escでの中止、解説の更新、候補比較、添削差分表示を確認しました。

全アプリ、全言語、複数ディスプレイ、長文の意味保持を網羅的に検証したものではありません。Naniとは別の製品で、同等の翻訳品質・音声品質を保証しません。クラウド同期、チーム管理、課金、自動アップデートはありません。原文・訳文を外部AIへ送信する処理はありません。
