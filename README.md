# JOPT翻訳 0.3.0 Beta

[Mac版ダウンロード・導入ガイド](https://jopt-translate-mac.directors-ai.chatgpt.site)

Apple Silicon / macOS 26.4以降 / Apple Intelligenceが必要です。Developer ID署名・Apple公証のない試用版です。

## アカウント・履歴同期

- Googleログインが必須になりました。Gmail・Driveへのアクセス権限は求めません。
- 履歴に保存した原文・訳文・解説・文脈・日時などをアカウントに紐づけて同期します。サーバーの保存期間は90日です。
- 運営管理者の竹田は保存内容を閲覧できます。ログイン前にこの点を説明し、管理画面は指定のGoogleアカウントへ限定しています。閲覧・抽出操作は記録します。
- 品質改善・学習用データへの提供は別の任意設定で、初期状態はオフです。学習用の抽出は、現在同意している利用者の同意後の新しい履歴に限定します。外部モデルへ学習データを自動送信する機能はありません。
- 旧版の端末内履歴は自動で送信しません。設定で取り込みを選んだ場合だけ同期します。
- ログイン情報はMacのキーチェーンへ保存。アカウント別のローカル履歴・削除の同期・ログアウト・同期データ削除に対応しています。

## 翻訳・解説・UI

- インストール済みのApple専用翻訳モデルを優先。汎用の端末内モデルで書き直すと文・条件・通貨が変わる事例を受け、意味を優先した訳文と、AIによる表現調整を分けました。
- 複数文を文ごとに処理し、画面から取得した2行のうち1行が欠ける問題を修正。
- 簡体字・繁体字、限定した定型表現・用語、来週中の期限、不確実性、円の表記などを改善。
- 外国語から日本語へ訳した場合の解説では、原文の表現を優先。引用範囲と根拠のない丁寧さの推測を見直しました。
- 画面翻訳は前回の添削モードを引き継がず翻訳へ切り替えます。
- 挨拶・説明・補助文字・アカウント表示・同期状態を改善し、使い始めの案内を整理しました。
- 起動時の旧履歴の一時表示を防ぎ、キーチェーンの読み書きを非同期化しました。

## 品質の確認範囲

全16対応言語の43ケースを実生成。重点32ケースは英語・韓国語・中国語（簡体字・繁体字）と日本語への翻訳です。自然さ・口調に関する12件の低重大度のAI調整案を、レビュー用CSVとともに掲載しています。

これはAIによる評価です。ネイティブ話者による確認は未実施で、全言語・全表現の正確さやNaniと同等の品質を保証するものではありません。
