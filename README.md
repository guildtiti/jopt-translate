# JOPT翻訳 0.5.0 Beta

[ダウンロード・導入ガイド](https://jopt-translate-mac.directors-ai.chatgpt.site)

- 主訳と、もう1つの言い方を自動で提案。設定でオフにできます。別案は訳文1,300文字までで、条件を保てない場合は主訳と案内を残します。
- 翻訳時に文脈・文体を自動で反映。失敗した場合も基本の訳文を使えます。
- 画面下から、同じ訳文について続けて質問できます。説明と修正案を区別し、修正案は確認してから採用。「英文にして」など明示した言語も指定できます。
- 候補・質問と回答も履歴に保存し、同じGoogleアカウントで同期。保存内容は運営管理者が閲覧できます。旧版の履歴とも互換性を維持します。
- 履歴の境界をドラッグして幅を変更。検索・ピン絞込・全文展開のできる一覧を追加しました。
- 設定を5カテゴリへ整理。狭いログイン画面は1列にまとめ、文字の折り返しを改善しました。

追加質問は1件1,200文字、6往復・会話合計6,000文字までです。端末内AIのトークン上限に達した場合も、会話を残して新しい質問を始める必要があります。AIの意味の照合は、全言語・全表現の正しさを保証するものではありません。

Apple Silicon / macOS26.4以降 / Apple Intelligence / Googleログインが必要です。Developer ID署名・Apple公証のないBetaです。別Mac初回起動・人のネイティブレビュー・Naniの有料機能との同等性は未確認です。

2026年11月2日公開。実AIを含む36件と同期API16件の自動試験、実機の自動候補・解説・4往復・採用・履歴復元、公開ダウンロードの原本一致を確認しました。16言語43ケースの評価には低重大度の調整候補4件が残ります。英訳で試験用見出しが省かれた例もあり、追加質問で戻せました。採用前に全文を確認してください。
