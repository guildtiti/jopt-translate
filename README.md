# JOPT翻訳 0.4.0 Beta — 訳文中心のUIへ刷新

[Mac版ダウンロード・導入ガイド](https://jopt-translate-mac.directors-ai.chatgpt.site)

## 画面と操作を変えました

- 翻訳後は原文を小さなカードにまとめ、訳文とニュアンス解説を中心に表示します。「編集」から原文を直せます。
- 訳文は22px、解説は14pxへ。表現ごとに見出しと説明を分け、青い背景のカードで読みやすくしました。
- コピー、丁寧・カジュアル・短く、言い方の比較を訳文の近くにまとめました。逆翻訳・要約などは「…」から選べます。
- 返信や追記は「このあと、どう伝えますか？」から開きます。
- 次の文章を入力する欄を画面下に表示。原文を置き換えずに、新しい翻訳を始められます。
- はじめての画面に、試せる例文と画像/PDF・画面取得のカードを用意。履歴・モード切替・余白・色・ボタンも見直しました。

インストール済みNaniの画面を実際に操作して、入力・結果・調整の流れを確認しました。Naniのコード・画像・ロゴ・キャラクターは使っていません。

## 比較候補の改善

実機試験で、候補に「Sure, here is the rewritten text:」が混ざり、「可能なら」という条件が落ちる例を確認して修正しました。候補の出力形式を指定し、条件・質問・数値を確認してから表示します。候補の採用後は、その表現の解説を更新します。

検査は有限です。すべての言語や表現の意味保持、Naniと同じ品質を保証するものではありません。元の訳文を残したまま候補を比べ、採用する操作は利用者が選べます。

## 導入と既存機能

Apple Silicon / macOS 26.4以降 / Apple Intelligence / Googleログインが必要です。Google認証の本番公開、履歴同期、指定管理者による閲覧、品質改善提供の任意設定を引き継ぎます。

Developer ID署名・Apple公証のない試用版です。更新後にショートカットや画面翻訳の権限を再登録する必要がある場合があります。[導入ガイド](https://jopt-translate-mac.directors-ai.chatgpt.site)を確認してください。
