# JOPT翻訳 0.7.0 Beta

[ダウンロード・導入ガイド](https://jopt-translate-mac.directors-ai.chatgpt.site)

- 解説言語を日本語・English・한국어・简体中文・繁體中文へ切り替えられます。ニュアンス解説と追加質問の説明に使い、訳先は変わりません。
- 履歴保存期間を1・7・30・90・180・365日・無期限から選べます。初期90日。Googleアカウント共通で、短縮時は削除対象件数を確認します。ピン留めも対象で、削除した本文は復元できません。
- 名前付きスタイルを20件まで保存。複製・編集・順番変更・非表示・再表示に対応し、翻訳画面から1つ選んで使います。履歴には生成時の指示を残します。

解説言語とスタイル一覧はMacごとの設定です。保存期間と履歴はGoogleアカウントで同期します。履歴保存内容は運営管理者が閲覧できます。学習用の抽出は任意同意の対象だけで、文体の指示を独立した抽出項目には加えていません。

実AIを含む49件、認証・同期・保存期間のAPI33件が成功。5言語の期限解説は、実在する句に対応した既知の説明を使います。一般生成の語彙・自然さ・意味の正しさは人の確認が必要です。今回16言語43ケース全体を再測定したものではありません。

Apple Silicon / macOS26.4以降 / Apple Intelligence / Googleログインが必要です。Developer ID署名・Apple公証のないBetaです。更新で権限の再登録が必要になる場合があります。別Mac初回起動・人のネイティブレビューは未実施です。
